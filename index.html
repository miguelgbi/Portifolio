Sistema de Gerenciamento de Carros

Desenvolvimento de uma aplicação para gerenciamento de veículos.

01. Problema

A necessidade de organizar e facilitar o gerenciamento de veículos, permitindo controlar os carros cadastrados e sua disponibilidade para venda e aluguel.

02. O que eu fiz

Desenvolvi um sistema de gerenciamento de carros que permite cadastrar, listar, vender, alugar e excluir veículos, facilitando o controle e a organização das informações.

03. Como eu fiz

Utilizei React para desenvolver a interface do sistema, HTML para a estruturação, CSS para a estilização e Firebase para armazenar e gerenciar os dados dos veículos.

04. Resultado

Desenvolvi uma aplicação para gerenciamento de veículos, oferecendo funcionalidades de cadastro, listagem, venda, aluguel e exclusão de carros.
